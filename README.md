# Jelajah Ayat

Platform pembelajaran interaktif Bahasa Melayu tentang ayat aktif dan ayat pasif.

## Pengaktifan GitHub Pages

1. Buka tetapan repositori ini dan pilih **Pages**.
2. Pada bahagian **Build and deployment**, pilih sumber **GitHub Actions**.
3. Aliran kerja **Terbitkan Jelajah Ayat** akan berjalan secara automatik. Selepas berjaya, pautan laman akan dipaparkan dalam tetapan Pages.

Fail `index.html` berada di aras utama. Aliran kerja dalam `.github/workflows/deploy.yml` menerbitkan laman setiap kali perubahan dihantar ke cabang `main`.

## Penyimpanan kemajuan

Nama, avatar, bintang, lencana dan kemajuan disimpan pada pelayar/peranti yang digunakan. Versi ini tidak mempunyai akaun murid atau pangkalan data berpusat; kemajuan tidak disegerakkan antara peranti.

Kandungan tatabahasa merujuk kepada PRPM, Dewan Bahasa dan Pustaka. Pautan rujukan tersedia dalam platform.
